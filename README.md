# BLACK SQUARES

4×4の黒塗りゲームを、完全手のCPUと遊べるブラウザゲームです。ランダムに提示される盤面を読み、先手か後手を選んで3連勝を目指します。

## 遊び方

1. 初期盤面を見て、人間が先手か後手かを選びます。
2. 白マスを1つ以上含む2×2を選び、4マスをすべて黒にします。
3. CPUと交互に操作し、操作できなくなった側が負けです。
4. 3連勝するとクリアです。3局には先手必勝盤面と後手必勝盤面が必ず両方含まれます。

スマートフォンでは、2×2を1回タップして選択し、表示された外枠を確認してから同じ場所をもう1回タップすると着手します。3問目の初期盤面には必ず白マスが8個以上あります。

`index.html` をブラウザで直接開けば遊べます。外部ライブラリやビルド工程はありません。

## 完全解析

盤面を16ビット整数、9種類の操作をビットマスクとして表現しています。操作のたびに黒マスが増えるためゲーム木には循環がなく、全65,536局面を後ろ向きに解析できます。

- 先手必勝：54,564局面
- 後手必勝：10,972局面

CPUは勝ち局面では必ず相手の負け局面へ移るため、理論上勝てる側を担当した場合は必ず勝ちます。

## テスト

ブラウザで `tests.html` を開くか、Node.js がある環境で次を実行します。

```sh
node tests.js
```

このディレクトリをGitHubリポジトリへ配置し、Settings → Pages から対象ブランチのルートを公開してください。すべて相対パスのため、プロジェクトサイトでもそのまま動作します。

## ファイル

- `game.js`：ゲームエンジン、完全解析、CPU
- `app.js`：画面と対局進行
- `tests.html` / `tests.js`：回帰テスト
- `game-design.md`：設計書
